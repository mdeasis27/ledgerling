# Income is every positive amount, refunds included

The brief defines income as "the sum of positive amounts". We follow it literally rather than counting only the `income` category, so a refund in `shopping` raises income for the month (Feb 2026 fixture: 629,949 cents, not 625,100) while never reducing spend. The visible tool cases only cover months without refunds, so a reader could reasonably "fix" this to category-based income; don't.
